# Task Tracker

## Структура проекта
- `apps/frontend` - Next.js приложение
- `apps/backend` - NestJS API
- `packages/config` - Общие конфиги
- `packages/shared-types` - Общие типы TypeScript
- `docs` - Общая документация

## Быстрый старт
```bash
pnpm install
pnpm dev  # Запускает и frontend, и backend
